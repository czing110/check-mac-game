# check-mac-game

一个用于核验 Windows 游戏在 macOS 上能否运行的 Codex plugin/skill。它会整理 Steam、官方页面、CodeWeavers、社区实测等证据，并在结论明确为可玩时生成统一风格的 8 张海报。

## 安装

### 方式一：作为插件安装（推荐）

1. 下载仓库中的 `check-mac-game-plugin-1.0.6-portable.zip`。
2. 解压缩。解压后应看到一个包含 `.codex-plugin/plugin.json` 和 `skills/check-mac-game/` 的插件文件夹。
3. 在 Codex 的插件/技能导入入口选择这个文件夹，或把整个文件夹放进 Codex 的本地插件目录。
4. 重启或重新加载 Codex。插件清单中的名称应显示为 **Check Mac Game**。

不要只复制里面的 `SKILL.md`，也不要把压缩包里的文件全部散落到同一个目录；`.codex-plugin` 和 `skills/check-mac-game` 的层级需要保留。

### 方式二：只安装 skill

如果使用的 agent 不支持插件清单，可以把压缩包内的 `skills/check-mac-game/` 整个文件夹复制到该 agent 的 skills 目录，并确保文件夹内的 `SKILL.md`、`references/`、`scripts/` 和 `assets/` 保持原有层级。

## 怎么使用

安装完成后，直接用自然语言提问即可：

```text
《双影奇境》Mac 可以玩吗？
```

查询结束后，如果希望生成海报，只需单独回复：

```text
海报
```

也可以直接请求：

```text
《深岩银河》海报
```

只有结论确认可玩或需要 CrossOver 才能玩时才生成海报；明确不能玩或证据不足时，不生成海报。

## 结果规则

- “需要 CrossOver”表示游戏可以在 Mac 上运行，但不是原生 macOS 版本。
- Linux 兼容性不作为 Mac 结论，也不会写入最终结论。
- CodeWeavers 的 Mac Rating、测试版本和用户实测优先作为 CrossOver 证据。
- 本地采集器遇到 DNS、robots、403、超时或页面结构变化时，不能把“采集失败”当成“不能玩”。应继续尝试精确页面、英文名检索、浏览器核验或可靠的替代来源。
- 如果仍无法取得足够证据，结论必须写成“暂时无法确认”，不能伪造评级或实测结果。
- 兼容反馈链接必须是全文最后一行，放在“分享与反馈”区块内。

## 海报输出

海报页面包含 8 种固定模板和每张海报的下载按钮。模板会保留游戏标题、背景图、CrossOver 结论、星级、来源提示和交互布局；生成内容只使用当前游戏对应的素材。

## 更新

以后更新时，下载 GitHub 上的最新压缩包，删除旧版插件文件夹后替换为新版，再重新加载 Codex。不要把新旧版本的 `SKILL.md`、`references/` 或模板混在一起。

当前版本：`1.0.6`

### 1.0.6 更新说明

- 扩大自然语言自动调用范围：询问 PC、Steam、Windows 游戏、游戏库、购买前确认、安装运行、性能表现或是否需要 CrossOver 时，均可自动识别。
- 普通 Mac 故障排查和非游戏软件问题不会误触发。

### 1.0.5 更新说明

- CodeWeavers 抓取遇到 403、robots、超时或空结果时，优先用 Agent 可控制的真实浏览器打开精确游戏页；浏览器无法取证后才尝试精确页索引。
- 遇到验证码或登录验证时暂停，请用户完成验证后继续。
- 增加查询阶段、耗时、来源状态和恢复结果的结构化日志，便于排查问题。
- 普通兼容性查询取得结论后返回；用户询问玩法、解决办法或提供教程链接时，再检索详细教程。
- 版本号与详细变更记录随包提供。结构检查及 11 项离线回归测试已通过；浏览器恢复仍取决于宿主工具和网站访问状态。

## 隐私、版权与限制

本项目不包含游戏官方图片、Logo、截图或生成的海报。运行时可能访问第三方网站；请遵守这些网站的使用条款和当地版权法规。网络不可用时，结果可能只能保留为“暂时无法确认”。

### CrossOver 下载链接说明

CrossOver 下载链接包含追踪参数，仅用于统计下载来源；不涉及分销、返佣或用户额外费用。
